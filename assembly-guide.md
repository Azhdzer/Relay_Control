# Сборка прототипа — шаг за шагом

## Что понадобится прямо сейчас

- Arduino Nano
- LCD 1602A с I2C-платой HW-61
- Релейный модуль CW-021 (2-канальный)
- 1 красный светодиод
- 1 резистор 220 Ом (красно-красно-коричневый)
- 1 кнопка
- Провода Dupont или любые тонкие проводки
- USB-кабель от Nano к ПК

---

## Шаг 1 — Припаять I2C-плату к LCD

Если плата HW-61 ещё не припаяна к LCD:

1. Положите LCD лицом вниз.
2. Совместите 16 контактов HW-61 с 16 пинами на LCD.
3. Припаяйте все 16 ног.
4. Убедитесь, что нет перемычек между соседними пинами.

После пайки у вас будет один блок: LCD + I2C сзади.

---

## Шаг 2 — Подключить LCD к Arduino Nano

| LCD I2C (HW-61) | Arduino Nano |
|---|---|
| VCC | 5V |
| GND | GND |
| SDA | A4 |
| SCL | A5 |

Всего 4 провода.

```
Nano 5V  ──────── VCC  (HW-61)
Nano GND ──────── GND  (HW-61)
Nano A4  ──────── SDA  (HW-61)
Nano A5  ──────── SCL  (HW-61)
```

---

## Шаг 3 — Подключить релейный модуль CW-021

| Relay CW-021 | Arduino Nano |
|---|---|
| VCC | 5V |
| GND | GND |
| IN1 | D7 |
| IN2 | не подключать |

```
Nano 5V  ──────── VCC  (CW-021)
Nano GND ──────── GND  (CW-021)
Nano D7  ──────── IN1  (CW-021)
```

> ВАЖНО: модуль активен LOW.
> D7 = LOW  → реле ВКЛЮЧАЕТСЯ (замкнуто)
> D7 = HIGH → реле ВЫКЛЮЧЕНО (разомкнуто)

---

## Шаг 4 — Подключить LED-индикатор состояния реле

```
Nano D8 ──── [резистор 220 Ом] ──── (+) LED красный (-) ──── Nano GND
```

LED горит = реле включено = нагрузка получает питание.

---

## Шаг 5 — Подключить кнопку аварийного выключения

```
Nano D2 ──── кнопка ──── Nano GND
```

Без резистора, потому что в скетче используется INPUT_PULLUP.
Кнопка нажата = принудительное выключение, приоритет выше всего остального.

## Шаг 6 — Загрузить тестовый скетч

Создайте файл `prototype_test.ino` и загрузите в Nano через Arduino IDE:

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// ── пины ──────────────────────────────────────
#define RELAY_PIN   7   // LOW = реле ON (модуль активен LOW)
#define LED_PIN     8   // HIGH = LED горит
#define BUTTON_PIN  2   // INPUT_PULLUP, нажата = LOW

// ── LCD ───────────────────────────────────────
// Попробуйте 0x27, если не работает — смените на 0x3F
LiquidCrystal_I2C lcd(0x27, 16, 2);

// ── состояние ─────────────────────────────────
bool relayState = false;         // false = OFF
unsigned long lastToggle = 0;
const unsigned long INTERVAL = 3000; // мс между переключениями в тесте

void setRelay(bool on) {
  relayState = on;
  // CW-021 активен LOW: ON = LOW, OFF = HIGH
  digitalWrite(RELAY_PIN, on ? LOW : HIGH);
  digitalWrite(LED_PIN,   on ? HIGH : LOW);

  lcd.setCursor(0, 1);
  lcd.print(on ? "RELAY: ON       " : "RELAY: OFF      ");
}

void setup() {
  pinMode(RELAY_PIN,  OUTPUT);
  pinMode(LED_PIN,    OUTPUT);
  pinMode(BUTTON_PIN, INPUT_PULLUP);

  // Безопасное состояние при старте
  setRelay(false);

  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("Prototype OK    ");
  lcd.setCursor(0, 1);
  lcd.print("RELAY: OFF      ");

  Serial.begin(9600);
  Serial.println("Prototype ready");
}

void loop() {
  // Аварийная кнопка — наивысший приоритет
  if (digitalRead(BUTTON_PIN) == LOW) {
    setRelay(false);
    lcd.setCursor(0, 0);
    lcd.print("EMERGENCY OFF   ");
    delay(200); // простой дебаунс
    return;
  }

  // Тест: переключаем реле каждые 3 секунды
  if (millis() - lastToggle >= INTERVAL) {
    lastToggle = millis();
    setRelay(!relayState);
    lcd.setCursor(0, 0);
    lcd.print("TEST MODE       ");
    Serial.println(relayState ? "RELAY ON" : "RELAY OFF");
  }
}
```

## Шаг 7 — Проверка LCD-адреса

Если экран не показывает ничего после загрузки, запустите этот I2C-сканер:

```cpp
#include <Wire.h>
void setup() {
  Wire.begin();
  Serial.begin(9600);
  for (byte addr = 1; addr < 127; addr++) {
    Wire.beginTransmission(addr);
    if (Wire.endTransmission() == 0) {
      Serial.print("Found I2C at 0x");
      Serial.println(addr, HEX);
    }
  }
}
void loop() {}
```

Запустите, откройте Serial Monitor (9600 baud). Адрес будет `0x27` или `0x3F`.
Потом впишите его в строку `LiquidCrystal_I2C lcd(0x27, 16, 2);`.

## Шаг 8 — Проверка реле без нагрузки 24V

1. Подключите Nano к USB.
2. Загрузите тестовый скетч.
3. Смотрите: реле должно щёлкать каждые 3 секунды.
4. LED должен загораться и гаснуть синхронно со щелчком.
5. Нажмите кнопку — реле должно сразу выключиться.
6. LCD должен показывать "RELAY: ON / OFF" и "EMERGENCY OFF".

---

## Шаг 9 — Подключить 24V нагрузку (только после шага 8)

Только после того, как тест без нагрузки прошёл успешно:

1. Отключите USB.
2. Подключите:
   - `+24V` от БП → `COM` реле
   - `NO` реле → `+24V` к нагрузке
   - `GND` БП → `GND` нагрузки
3. Подключите USB снова.
4. Убедитесь, что при старте нагрузка не питается (реле OFF).
5. Убедитесь, что через 3 секунды нагрузка включается, через 3 — выключается.
6. Убедитесь, что кнопка всегда отключает нагрузку.
